\section{Synopsis}
A solution is proposed for the problem of best matching of a unit cell to a supercell.


	
	\section{Introduction}

\citeasnoun{santoro1980determination} enumerated transformation 
{matrices} for generating coincidence site lattices (sublattices)
from a given unit cell description. They create one exact representation
of a sublattice for each choice of input and transformation. The
general solution requires awareness of different choices of unit cells, 
alternative choices for basis vectors for actual or near degeneracies,
and allowance for lattice distortion (for instance, because of
replacement on one metal ion with another).

The program NIST*LATTICE \cite{nistlattice,nisttn1290}
is similar to CmdLMP3. NIST*LATTICE uses a more obscure
matrix generation module and does not have a simple measure
of fit, instead relying on error windows on each of the 6
cell parameters.
	
	\citeasnoun{andrews2026approximate} describe a general solution for finding 
	approximate relationships between unit cells that are similar but
	not necessarily sampled from the identically-same lattice.
	A user of that software (CmdLMP3) asked if the same could be applied to
	the determination of unit cells to supercells. Here we extend their method to the case of supercells. (CmdLMP3
	is a component of LatticeRepresentationLib; see Section~ \ref{refAvailability}.
		
	Figure \ref{figProcess} summarized the operations of 
	\citeasnoun{andrews2023approximating} that are used to compare
	a ``reference'' unit cell to a ``probe'' unit cell; the
	results are returned in the coordinate frame of the reference. 


\begin{figure}
	\includegraphics[width=\columnwidth]{supercell1}
	\label{figProcess}
	\caption{
		Flowchart of the approximate lattice matching process of ~\citeasnoun{andrews2026approximate}.
		Reference and probe cells are converted to primitive form and reduced.
		Both the primitive and the reduced cell of each are passed to the matching stage, giving four pairings.
		A library of matrices supplies candidate transformations of the probe:
		matrices of determinant one enumerate alternative settings of the probe lattice,
		and matrices of determinant n enumerate the derivative lattices of index n.
		Each candidate transformation is applied to the probe lattice
		and scored by the \PIII{} \cite{andrews2026p3} distance to the reference.
		The transformed cell is not reduced again before scoring, so the score is 
		calculated in the 
		coordinate frame of the reference.
		Accepted matched approximate cells are carried back through the reduction and primitive-conversion inverses
		to the frame of the initial reference.

}

\section{Algorithm}

The algorithm described above and in Figure \ref{figProcess} suffices for matching lattices that are somewhat
similar to each other, but the question of matching a cell to a supercell
can be tackled with a modest modification: where matching as 
described in Figure \ref{figProcess} is
done using unimodular matrices, by replacing the library of transformation
matrices with a library  of matrices that have larger determinants, approximate
supercell relationships can be determined.

For instance, for a given unit cell, to find supercells that have 
a base vector tripled a library of transformations with 
determinant=3.0 would be used. 

A library of matrices for a supercell of order n can be 
constructed by a function that uses 9 nested loops, one for
each element of the 3x3 transformation matrices. For 
transformations of order n, the loops would run from -n to
+n, and matrices with determinant = n would be added to the
library.

\citeasnoun{santoro1980determination} addressed the question 
of supercells using a limited set of matrices, the \textbf{H}ermite \textbf{N}ormal \textbf{F}orm (HNF) \cite{hermitewiki}. For a
given supercell order (equal to the determinant of the
transformation matrix between original and supercell), 
the HNF gives and one example of each possible lattice. The issues that arise are that the possible exchanges of axes
and inexact, measured data are not addressed.

\subsection{Reference vs. probe decision}

For a given input pair of unit cells, the decision to 
search for supercells of the reference cell requires
that the reference have the smaller primitive unit
volume of the pair. When 2 input cells are compared
and the ratio of he volumes is not near 1.0, then
the smaller of the 2 is designated as the reference
cell and the other as the probe. CmdLMP3 assumes that the
first input cell of a pair to be compared is the reference.
In the case where the reference cell has the larger 
primitive volume, then the reference and probe cells
are interchanged.

The output of the results of matching
shows the transformation from the input probe cell to
the frame of the input reference cells. That might be
the reverse of the choice that the user desires, so
 the inverse 3x3 matrix is also output.
